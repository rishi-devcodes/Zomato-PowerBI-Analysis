# Zomato Restaurants Analysis (Power BI)
## Project Overview
This project analyzes Zomato restaurant data to understand patterns in restaurant distribution, cuisine popularity, and service availability.

## Key Insights
- New Delhi has the highest number of restaurants
- North Indian cuisine dominates the dataset
- Most restaurants do not offer table booking
- Online delivery is limited

## Tools Used
- Power BI
- Excel
